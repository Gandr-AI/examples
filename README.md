# Gandr examples

Run a voice agent line in one minute. Every example needs a key from [gandr.ai](https://gandr.ai): the free key starts at 50,000 tokens. Break something and we want to hear it: open an issue.

| Example | Shows |
|---|---|
| `readback_demo.py` | The lines that break phone agents: order IDs, dates, phone numbers, addresses, read back correctly |
| `batch_ivr.py` | Batch-render an IVR prompt library with the Python SDK |
| `streaming_ws.py` | The WebSocket lane, audio streams back as it is generated, the lane voice agents use |
| LiveKit agent | See [Gandr-AI/gandr-livekit](https://github.com/Gandr-AI/gandr-livekit), full plugin + template |
| MCP agents | See [Gandr-AI/gandr-mcp](https://github.com/Gandr-AI/gandr-mcp) |

**Pricing:** unlimited, unmetered stream plans from **$150/mo** (annual), or **$10 a month for one million tokens** (one token is one character), [gandr.ai/pricing](https://gandr.ai/pricing).

Docs: [gandr.ai/docs](https://gandr.ai/docs)
