# Gandr examples

Small, runnable examples against the live API. Every one needs a key from [gandr.ai](https://gandr.ai).

**Pricing:** unlimited, unmetered stream plans from **$150/mo** (annual), or **$10 per million characters** pay as you go — [gandr.ai/pricing](https://gandr.ai/pricing).

| Example | Shows |
|---|---|
| `batch_ivr.py` | Batch-render an IVR prompt library with the Python SDK |
| `streaming_ws.py` | The WebSocket lane — first audio byte in ~116 ms warm, the lane voice agents use |
| LiveKit agent | See [Gandr-AI/gandr-livekit](https://github.com/Gandr-AI/gandr-livekit) — full plugin + template |
| MCP agents | See [Gandr-AI/gandr-mcp](https://github.com/Gandr-AI/gandr-mcp) |

Docs: [gandr.ai/docs](https://gandr.ai/docs)
